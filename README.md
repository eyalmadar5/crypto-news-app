# לוח מטבעות דיגיטליים — MVP לוקאלי

אתר מקומי (רץ על המחשב שלך, בלי דומיין) שמרכז חדשות וטוויטר... לא, בלי טוויטר בשלב הזה (ראה הסבר למטה) — חדשות ומחירים בזמן אמת עבור: **XRP, ALGO, HBAR, XDC, XLM**.

## מה יש כאן

- **מחירים** — נשלפים מ-CoinGecko (חינמי, בלי מפתח API).
- **חדשות** — נשלפות מ-RSS של אתרי חדשות קריפטו בינלאומיים (CoinDesk, Cointelegraph, Decrypt, CryptoSlate, The Daily Hodl) + בלוגים רשמיים של הפרויקטים (XRPL, Stellar, Algorand, Hedera), ומסוננות אוטומטית כך שרק כתבות שמזכירות אחד מ-5 המטבעות שלך נשמרות.
- **רענון ידני** — כפתור "רענון נתונים" באתר מושך עדכונים חדשים. (בהמשך, כשתרצה, קל להפוך את זה לרענון אוטומטי כל 30-60 דקות עם cron/scheduler).
- כל הנתונים נשמרים ב-SQLite מקומי (`backend/crypto_news.db`) כך שהאתר עובד גם בלי לרענן כל פעם מחדש.

## למה אין טוויטר/X כרגע

כמו שדיברנו — מאז פברואר 2026 ל-X אין טייר חינמי או זול לפיתוח חדש; זה תשלום-לפי-קריאה עם עלות משמעותית. כדי לא לחייב אותך בכרטיס אשראי כבר ב-MVP, השארתי את זה בחוץ. אם בהמשך תרצה להוסיף את זה (למשל מעקב אחרי חשבונות רשמיים של הפרויקטים), זה תוסף קטן יחסית להוסיף לארכיטקטורה הקיימת.

## הרצה מקומית

דורש Python 3.9+.

```bash
cd backend
python3 -m venv venv
source venv/bin/activate      # ב-Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload
```

ואז פותחים דפדפן בכתובת: **http://localhost:8000**

בלחיצה ראשונה על "רענון נתונים" האתר ימשוך חדשות ומחירים אמיתיים (נדרש חיבור אינטרנט רגיל — לא עבד בסביבת הבדיקה שלי כי היא חסומה לדומיינים חיצוניים, אבל יעבוד אצלך).

## פריסה אונליין בחינם (Render)

אם אתה רוצה כתובת URL אמיתית שאפשר לפתוח מכל מקום (לא רק על המחשב שלך), אפשר להעלות את זה חינם ל-Render — בלי כרטיס אשראי, בלי דומיין משלך (תקבל כתובת כמו `crypto-news-dashboard.onrender.com`).

**המגבלה היחידה:** בטייר החינמי השירות "נרדם" אחרי 15 דקות בלי תנועה, והכניסה הבאה לוקחת כדקה להתעורר. לשימוש אישי זה לגמרי סביר.

שלבים:

1. **צור חשבון GitHub** (אם אין לך) ותעלה את התיקייה הזו כ-repository חדש:
   ```bash
   cd crypto-news-app
   git init
   git add .
   git commit -m "crypto news dashboard"
   git branch -M main
   git remote add origin https://github.com/USERNAME/crypto-news-app.git
   git push -u origin main
   ```
2. **צור חשבון חינמי ב-[render.com](https://render.com)** (מתחברים עם GitHub, בלי כרטיס אשראי).
3. לוחצים **New → Blueprint**, בוחרים את ה-repo שיצרת. Render יזהה אוטומטית את קובץ `render.yaml` שכבר נמצא בתיקייה ויגדיר הכל לבד (build command, start command, פורט).
4. לוחצים **Apply** וממתינים כמה דקות לבנייה הראשונה. בסיום תקבל כתובת URL ציבורית קבועה.

מהעדכון הבא, כל `git push` ל-`main` יעדכן אוטומטית את הגרסה החיה.

## מבנה הפרויקט

```

├── backend/
│   ├── app.py          # שרת FastAPI + API
│   ├── fetcher.py       # לוגיקת שליפת RSS ומחירים

│   └── requirements.txt
├── frontend/
│   └── index.html        # הדשבורד (עמוד יחיד, ללא build step)
└── README.md
```

## איך מוסיפים מטבע חדש

עורכים את `backend/sources.py`, מוסיפים שורה ל-`COINS` עם הסימול, שם תצוגה, `coingecko_id` (אפשר למצוא ב-coingecko.com בעמוד המטבע), ומילות מפתח לזיהוי בכתבות.

## איך מוסיפים/מסירים מקור חדשות

עורכים את `NEWS_SOURCES` או `OFFICIAL_SOURCES` באותו קובץ — כל שורה היא `"שם תצוגה": "כתובת RSS"`.

**הערה חשובה:** כתובות ה-RSS של הבלוגים הרשמיים (XRPL, Stellar, Algorand, Hedera) הן נקודת פתיחה סבירה אבל פרויקטים משנים כתובות מדי פעם ולא לכולם RSS יציב. אם מקור מסוים לא עובד, האתר לא יקרוס — הוא פשוט ידווח על השגיאה ויתעלם מהמקור הבעייתי (אפשר לראות את זה בתגובת ה-API של `/api/refresh`). כדאי לבדוק מדי פעם שהכתובות עדיין תקינות, או להחליף במקור אחר איכותי שתמצא.

## מגבלות ידועות של ה-MVP הזה (בכוונה, כדי לשמור על פשטות)

- אין דירוג "חשיבות" אוטומטי של כתבות — כרגע כל כתבה שמזכירה את אחד המטבעות נכנסת. אם תרצה, השלב הבא הטבעי הוא לשלב מודל שפה שמדרג/מסכם כתבות לפי רלוונטיות אמיתית (למשל "שיתוף פעולה שנחתם" לעומת "מאמר דעה כללי").
- אין דדופ' חכם בין מקורות (אם שתי אתרים מסקרים אותה ידיעה, שתי הכתבות יופיעו בנפרד).
- אין היסטוריית מחיר/גרף — רק המחיר הנוכחי ושינוי 24 שעות.
- רץ רק לוקאלית; אין אימות משתמשים, HTTPS, וכו' — לא נדרש כרגע כי זה על המחשב שלך בלבד.
